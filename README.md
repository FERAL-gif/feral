# FERAL — sitio web

## Cómo publicarlo en GitHub Pages (gratis, 5 minutos)

1. Andá a github.com y creá un repositorio nuevo (público). Por ejemplo: `feral-site`.
2. Subí estos dos elementos a la raíz del repo:
   - `index.html`
   - la carpeta `images/` completa (con las ~19 fotos adentro)
3. En el repo, andá a **Settings → Pages**.
4. En "Source", elegí la rama `main` y la carpeta `/ (root)`. Guardá.
5. Esperá 1-2 minutos. GitHub te va a dar una URL como:
   `https://tu-usuario.github.io/feral-site/`

Esa URL ya es tu sitio en vivo. Podés apuntarla desde tu Instagram bio o desde donde quieras.

## Antes de publicar — dos cosas para completar

1. **Botón "Claim Your Seat"**: ya apunta a
   `https://www.edfringe.com/tickets/whats-on/feral` — revisá que ese link esté activo cuando Fringe abra ventas.

2. **Botón "Request Press Ticket"**: en `index.html`, buscá la línea que dice:
   ```
   href="PASTE_YOUR_GOOGLE_FORM_LINK_HERE"
   ```
   y reemplazala por el link de tu Google Form (instrucciones abajo).

## Si querés cambiar texto o fotos después

Todo el sitio es un solo archivo (`index.html`) con comentarios tipo `<!-- HERO -->`, `<!-- VISION -->`, etc. que marcan cada sección — es fácil de encontrar y editar directamente, o volver a pedirme que lo edite.
